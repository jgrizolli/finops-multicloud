# Suporte

Este projeto é mantido como material tecnico de estudo e implantacao. Nao tem SLA nem suporte oficial da Microsoft.

## Antes de pedir ajuda

| Situacao | Onde olhar |
|---|---|
| Algo nao instalou ou parou de funcionar | [docs/08-erros-regras-limites.md](docs/08-erros-regras-limites.md), secao de erros comuns (sintoma, causa, solucao) |
| O erro nao esta na lista | [docs/09-diario-de-bordo.md](docs/09-diario-de-bordo.md), com os erros reais da implantacao e o raciocinio de cada um |
| A URL da interface nao abre | `webapp/Diagnose-FinOpsWebApp.ps1` (somente leitura, entrega um veredito) |
| Duvida de comando | [docs/11-comandos.md](docs/11-comandos.md) |
| Duvida de conceito ou termo FOCUS | [docs/10-glossario-e-focus.md](docs/10-glossario-e-focus.md) |

## Ainda precisa de ajuda

Abra uma issue usando o template de bug e inclua: o comando executado, a saida completa do erro, o nivel escolhido
(0, 1 ou 2), a regiao e se a interface web esta em App Service ou Container Apps.
